# Multi Language Detection and Correction Tool

This project provides language detection and correction functionality for code-mixed paragraphs, made with the use of several pre-existing technologies.

## Usage

To run the program, download the source code, create a virtual environment, run the requirements.txt file through `pip install -r requirements.txt` and then run `python3 src/main.py`. This structure will change in later revisions of the repository.

## Dependencies

The project runs a pre-built TensorFlow Model compiled by Google's Language Detector Model created for developers under the Google AI Edge programme. The project also uses the QT Framework, a production level GUI design tool that provides clean and user-friendly UI design.
